# Segments 1000, 1959, 18c0 — program entry, startup/shutdown, mission loop, HUD

Symbols: `tools/re/symbols/seg_1000.tsv`, `seg_1959.tsv`, `seg_18c0.tsv`, globals in
`globals_1000.tsv`. Addresses are Ghidra `seg:off`; `DS:xxxx` is a DGROUP offset; far data
segments are written `5178:0156` (they are reached through the segment table at DS:CD5C..CDD6).

## 0. Conventions used below

* **Time.** The game clock `g_time` (DS:ECA6, int32) counts **1/256 s ticks**. A timer callback
  registered with the sound driver at 256 Hz increments the raw counter `g_ticks` (DS:ECB0); the
  frame code copies it into `g_time` (see §4). All durations below are in these ticks
  (0x100 = 1 s, 0x3C00 = 60 s).
* **Angles.** Headings are stored in 1/8 degree (0..2879); `>>3` gives degrees 0..359.
  `geo_bearing(a,b)` returns degrees.
* **Positions.** 3 × int32 (x @+0, altitude @+4, z @+8), 24.8 fixed point (world files store the
  integer part). "Units" below means the integer part.
* `rand(n)` = 2255:78D6 (value in 0..n-1, AX = n). `present()` = `gfx_present` (1000:1E87).
* A **team** (`g_teams[]`, DS:12E2, NULL-terminated array of far pointers) is a NULL-terminated list
  of unit far pointers (member 0 = team leader; team 0 member 0 = the Point Man = player) followed
  by fields (+0x22 order/state, +0x24 marker, +0x26 team type, +0x30 camera distance, +0x32 camera
  angle). Unit/team layouts are documented in `seg_2dbd.md`; only fields used here are listed in §17.

## 1. Module purposes

* **18c0** – Microsoft C 6 large-model run-time (startup, exit, long arithmetic, near heap,
  ctype, lseek...). Only `_astart`, `exit`, the long helpers and `tolower` matter to the port.
* **1959** – startup requirement checks, resource/library loading, palette loading, shutdown and
  fatal-error exits.
* **1000** – `main`, the in-mission loop (`mis_run`), game clock, time of day and sky gradients,
  cameras/view modes, frame rendering driver, HUD (compass, target info, text lines), the message
  queue (on-screen messages, hand signals, speech), insertion/extraction and time compression,
  picture loading, joystick calibration, world-object loading and probes, projectile firing,
  hit/damage application, AI noise events and procedural scenery (vegetation).
  The top-level game-mode state machine itself lives in 19ac:016D (documented here, §2.6).

## 2. Top-level program flow

### 2.1 C run-time entry (18c0:0034 `crt_astart`)
DOS version must be ≥ 2 (else return to DOS). Stack/heap set up in DGROUP (0x56BF), the PSP
block is shrunk (INT 21h 4Ah), `_BSS` DS:CEAC..F71F is zeroed, `_setargv` builds argv, the INT 0
(divide error) handler is installed, then `exit(main(argc, argv, envp))`. `exit` checks the
null-pointer area (XOR of DS:0000..0041 must be 0x55; failure prints R6001 and forces exit
code 255), restores INT 0 and terminates with INT 21h 4Ch.

### 2.2 `main` (1000:0000)
```
parse_command_line(argc, argv)   ; 19ac:04BE
sys_check_hardware()             ; 1959:007B
sys_load_resources()             ; 1959:0265
game_main_loop()                 ; 19ac:016D
sys_shutdown_and_exit()          ; 1959:0453 (never returns)
```

### 2.3 Command line (19ac:04BE)
`g_mission_number` (DS:EEBC) = −1. The arguments are scanned **from the last to argv[1]**; each
character is passed through `tolower`:

| char | effect |
|---|---|
| `t` | `g_title_enabled` (DS:022C) = 0 (skip EA logo/title) |
| `d` | `g_digital_sfx` (DS:45CC) = 0 |
| `?` or `h` | print usage (1959:04AA) and `exit(0)` |
| digit at position 0 of an argument | `g_mission_number` = digit × 10 |
| digit at position 1 | `g_mission_number` += digit |
| other chars / later digits | ignored |

After the scan: if the argument processed last (argv[1]) is exactly one character long,
`g_mission_number /= 10` (C truncation, so "5" → 5 and −1 → 0). Then `g_mission_number -= 1`.
If the result is < 0 or ≥ 0x50 (80): `g_mission_number = 0`, `g_game_mode` (DS:D7E4) = 2;
otherwise `g_game_mode = 6` (play that single mission, 1-based on the command line).

Usage text (1959:04AA) prints: "\n", "SEAL Team  V1.0", "\nCopyright (C) 1993  Andre Gagnon.  All
Rights Reserved.\n\n", the three requirement lines (conventional, EMS, VGA — see below, each
followed by a newline), "Command Line Options\n", "st [?] [h] [d] [t]\n", "  ?  Help\n",
"  h  Help\n", "  d  DIGITAL Sound Effects: Off\n", "  t  Title Screen: Off\n".
All DOS text output goes through 2255:10DE (INT 21h char output, CR added after LF).

### 2.4 Hardware checks — `sys_check_hardware` (1959:007B), in this order
1. `ems = ems_query_free_bytes()` (481c:0004). If `ems < 0xE6780` (944 000 bytes):
   `ems_shutdown()`, fatal **"Requires 976000 bytes of EMS memory."** (note: the tested threshold
   is 944 000, the text says 976 000).
2. `vga_detect()` (4e0c:0008: INT 10h AX=1A00h, display combination code 7 or 8 → `g_vga_flags`
   (DS:F42C) = 0x40). If bit 0x40 clear: `ems_shutdown()`, fatal **"Requires VGA graphics."**
3. Install the INT 24h critical-error handler (4edb:0005(1)).
4. Save the current BIOS video mode and equipment byte (2255:0D7E).
5. Enter graphics mode 6 (2255:04DE with AX=6: VGA 320×200×256 planar, two pages at A000/A400,
   `g_num_colors` DS:F262 = 0x100). On failure `fatal_exit`.
6. Initialise the far heap and the near heap (4e16:0006, 4e16:0181).
7. `ems_init()` (481c:002A). If more than 0x4000 bytes of EMS are free: `g_ems_mode` (DS:CF60) = 4.
8. `mem = mem_far_free_bytes()` (4e16:06F6). If `mem < 0x3B538` (243 000 bytes):
   `ems_shutdown`, remove the INT 24h hook, release the far heap, restore the video mode, fatal
   **"Requires 600000 bytes of conventional memory.\n"** (again the text differs from the test).
9. Detect input devices (19ac:2574): joystick present → DS:D832, mouse present → DS:D833,
   `g_cursor_mode` (DS:D820) = 1.

A requirement failure (`sys_fatal_msg`, 1959:0002) prints `"\n" + message + "\n"` through DOS
and calls `exit(0)`.

### 2.5 Resource loading — `sys_load_resources` (1959:0265)
1. `ealib_init(0xC4, 5124:0000, 41, 5124:023E, 1)` (4edb:006C, pascal): at most 0xC4 directory
   entries per archive; library table 5124:0000 with 41 14-byte entries (main, main2, main3, us,
   uq, u, c, p, cs, ps, cp, uf, ca, pi, cf, ua, uc, uw, up, cr, cw, pa, worlds, fxmu, fxsm, msns,
   fxhand, str, se, lbtn, bull, exsm, exlg, new, port, mdl, sound, point, camp, main4, d — each
   `<name>.lib`); name→library map 5124:023E with 1 entry (cursor.pic → main.lib); see
   seg_libs.md §5. Failure → `fatal_exit` (the message "Couldn't init libraries" is passed in BX
   but never printed).
2. Clear the screen to colour 0 (2255:0735); page setup check 2255:060D (failure → fatal).
3. `pal_load(0)` + `pal_apply(0)`: **pal2.pal** becomes the current palette.
4. Only if `g_num_colors == 256`: load `remap2.bin`..`remap5.bin` into DS:00EA..00F9 (the current
   remap DS:00E6 = remap2), `gradsky1.bin` → DS:00FA, `gradgrn1.bin` → DS:00FE.
5. Remaining engine initialisation, in order: 2255:AD4B (video page setup), 4db9:000C (4x6 debug
   font), 19ac:2D7F (cursor/wait/sight pictures and masks), 365e:921E (fonts), 2255:6699 (result to
   DS:F482), 2255:6C26, 2255:3E73, 2255:4CE5(0x10, DS:D78A), 2255:42B6(0x80, DS:CF8A), 2255:0177
   (3D engine), 49f8:00A6 (palette fader), 4a1c:00A0 (shake reset), 365e:4897, 4592:09AF (sound and
   music init — it calls `clk_reset_start_timer`, which registers the 256 Hz timer),
   4592:055E, 4e16:06F6 (result ignored), 365e:48F1 (reads the 16-byte difficulty file
   **st1.dfr** into 5178:0148, see §18), 19ac:25B3 (joystick calibration if a joystick was
   found, §11), 348e:19B0 (sprite banks), 365e:37BE, 365e:3D99(−1).

Palette helpers (1959): palette number *n* names come from DS:0102:
`0 pal2, 1 paln, 2 pals, 3 st, 4 se, 5 sm, 6 sn, 7 sl, 8 si, 9 sb, 10 so, 11..16 c0..c5`.
`pal_load(n)` frees the current palette, loads `<name>.pal` (768 bytes, 6-bit RGB) with
`ealib_load_far`, stores it in slot *n* (DS:D79C+4n) and as current (DS:0130). `pal_apply(n)`
waits for vertical retrace (port 3DAh bit 3) and writes all 256 entries to the DAC (3C8h/3C9h).
Only the current palette is valid (older slots keep dangling pointers — the port should keep one
current palette). The usual "change screen palette" sequence is 365e:3180(n, wait):
if `wait`: reset the clock and wait 0x180 ticks (1.5 s) pumping the fader; clear and present
the screen twice (once if no wait); `pal_load(n)`; if wait `pal_set_level(0x100)`; `pal_apply(n)`;
if wait `pal_set_level(0x100)` again (the fader then brings the level back).

### 2.6 Main loop — game-mode state machine (19ac:016D)
Values of `g_game_mode` (DS:D7E4):

| value | meaning | set by |
|---|---|---|
| 1 | campaign in progress ("Continue a Campaign") | main menu; also 2→1 after the first debriefing |
| 2 | main menu / new campaign | command line default, back-outs |
| 3 | practice mission | main menu |
| 6 | single mission given on the command line | command line |

Local state: `quit` (exit flag), `step` (0..8), `inner` (leave the inner loop).
```
365e:37BE()
loop:
  if quit: return
  if g_title_enabled:
      if g_game_mode != 6 and title_sequence() == 0: return      ; 19ac:0667 (Alt-X on title)
      g_title_enabled = 0
  if g_game_mode == 2:
      if main_menu() == 0: return                                  ; 365e:71D3 (sets mode 1/2/3)
      365e:37BE()
  if g_game_mode == 3:  PRACTICE (below)  else: CAMPAIGN (below)
```
Screen functions return 0 = quit program, 1 = back / cancel, other = continue.
`back()` below means `step = 0; 365e:3E14()` (free the screen resources).

**PRACTICE (mode 3)** – inner loop until `inner`:

| step | action |
|---|---|
| 0 | r = mission_select(g_campaign) (365e:74E8, calendar screen "Change Date or Year for different missions."). 0 → quit; 1 → `step=0, g_game_mode=2, inner=1`; else step 1 |
| 1 | word `g_campaign+4` = rand(8)+0x22 if byte `g_campaign+1` is odd, else rand(8)+0xA (practice randomisation); 365e:3D99(0x19 resp. 0); 365e:45A8(); 365e:3BC4(8); r = briefing(0) (365e:54BD). 0 → quit; 1 → `back()`; else step 2 |
| 2 | 365e:3180(0,1) (fade to pal2); `ui_show_please_wait()`; r = `mis_run()`. r == 1 (Alt-X) → quit; else `mis_cleanup()`, step 3 |
| 3 | r = debriefing(1) (365e:B511). 0 → quit; else `back()`, `g_game_mode = 2`, `inner = 1` |
| other | quit |

**CAMPAIGN (modes 1, 2, 6)** – inner loop; at the start of each iteration
`if step == 0 and g_game_mode != 2: step = 1`:

| step | action (skipped = go to step+1 when the condition fails) |
|---|---|
| 0 | (mode 2 only) r = campaign intro (365e:8095: year news picture new*.pic, palette sn, voice). 0 quit; 1 → `back(); g_game_mode = 2; inner = 1`; else step 1 |
| 1 | (skipped in mode 6) r = campaign screen (365e:9AA6, palette 7 sl; campaign record g_campaign). 0 quit; 1 → `back(); g_game_mode = 2; inner = 1; DS:022D = 0`; else step 2 |
| 2 | mode 6: `g_mission = load_mission()` (365e:237E) then free it (365e:24BC), step 3. Else r = mission_select (365e:74E8); 0 quit; 1 → `back()` (and since mode ≠ 2 the next iteration starts at step 1); else step 3 |
| 3 | 365e:45A8(); 365e:3CF0(); (mode 6 → step 4) r = briefing(0) (365e:54BD). 0 quit; 1 → `step -= 1; 365e:45F4()`; else step 4 |
| 4 | (skipped in mode 6) r = 365e:ABB9(0) (next pre-mission screen). 0 quit; 1 → step 3; else step 5 |
| 5 | (skipped in mode 6) r = 365e:D285() (insertion time / preview screen, §5). 0 quit; 1 → step 4; else step 6 |
| 6 | 365e:3180(0,1); `ui_show_please_wait()`; r = `mis_run()`. r == 1 → quit; else `mis_cleanup()`, step 7 |
| 7 | (skipped in mode 6) r = 365e:D659() (post-mission 3D sequence, view mode 6). r == 0 → quit; else step 8 |
| 8 | mode 6 → **quit** (a command-line mission exits to DOS). Else r = debriefing(1) (365e:B511); 0 quit; if `g_game_mode == 2` → 1; `DS:022D = 1`; `back()` |
| other | quit |

When `quit` is set the function returns and `main` calls `sys_shutdown_and_exit`.

**Title sequence** (19ac:0667): EA logo (19ac:05A4: clear, `pal_set_level(0x100)`, palette 4 `se`
with fade wait, picture 20 `ea.pic`, reset clock, blit+present twice, then wait until 0x500
ticks (5 s) have elapsed); then palette 3 `st` with fade, picture 1 `title.pic`, reset clock, load
the credits text resource `c` (365e:227C; 10 pages × 2 lines × 80 chars), music track 0 after a
0x300-tick wait. `counter = 1`, `page = 0`. Loop: blit title.pic, clip to the band
x 0..319, y 150..189; if `page < 9` draw the page's two lines (font DS:EEF8, colour 0x0F)
centred (x = 160 − width/2) at `y = 190 − (counter mod 64)` and `y + 12` (second line only if
not empty) — the credits scroll upwards; present. Every 0x10 ticks `counter++`; when
`counter mod 0x32 == 0` the counter restarts at 1 and `page++` (wraps at 10; page 9 is blank).
Exit on Enter or Esc (return 1), Alt-X (return 0) or after 0x5400 ticks (84 s, return 1); other
keys go to 19ac:0B2A (menu hotkeys) and keep the loop running.

### 2.7 Shutdown and fatal errors
* `sys_shutdown_subsystems` (1959:0420): 365e:3E14, 348e:1CD2, `pal_fade_shutdown`, 2255:0176,
  `clk_stop_timer`, sound shutdown 4592:0B85, mouse reset 49d2:008F, free fonts 4db9:015E,
  2255:062C, `ems_shutdown`. `sys_shutdown_and_exit` then calls `fatal_exit` (restore the saved
  video mode, release the far heap, `exit(g_exit_code DS:5BDE)`).
* `sys_fatal_error` (1959:045F, message in BX): ems_shutdown, remove INT 24h hook, stop screen
  shake, stop timer, sound shutdown, mouse reset, 2255:6C5C, restore video mode, release far heap,
  print the message if BX ≠ 0, `exit(1)`. Used for the 3D renderer overflow messages
  "View Buffer Too Small" (DS:063D) and "Object List Too Small" (DS:0653), see §8.

## 3. Screens, pictures and palettes

`pic_load(n)` (1000:1CCB) builds `<name>.pic` and loads it with `pxpk_load` into the single
full-screen picture buffer **DS:0526** (a surface descriptor; DS:0524 = 0xFF means freed):

| n | file | shown by | palette |
|---|---|---|---|
| 0 | mapscr.pic | map screen background (loaded at mission start 19ac:2E54, also 365e:E59A) | mission palette |
| 1 | title.pic | title screen | 3 st |
| 2 | brf.pic | briefing (365e:4C7A) | 0 pal2 |
| 3 | pwo.pic | orders screens (365e:4CEA, 365e:B022) | 10 so |
| 4 | mainm.pic | main menu (365e:6FE6 / 71D3) | 5 sm |
| 5 | intel.pic | intel / mission select (365e:7290 / 74E8) | 8 si |
| 6, 8 | — | nothing loaded | |
| 7 | debrf.pic | debriefing (365e:AFDC / B511) | 0 pal2 |
| 9 | load.pic | no direct caller found | |
| 10..13 | new, new2, new3, new4 .pic | campaign intro, index = campaign year (365e:8001) | 6 sn |
| 14..19 | cm0..cm5 .pic | 365e:D7D6, index DS:45A5 | 11..16 c0..c5 (365e:D94A) |
| 20 | ea.pic | EA logo | 4 se |

Blits: `pic_blit_to_screen(rect)` copies a rectangle of the picture to the same position of the
draw surface DS:F400; `page_copy_rect(rect)` copies from the displayed page (F40A/F414 by
`g_draw_page` DS:F260) to the draw page; `page_copy_full` does it for the whole 320×200 screen
(DS:4F94 = {0,0,320,200}). `gfx_present` sets the clip to the full screen, flips the pages
(2255:0649, AL=1, DL=0) and restarts the frame limiter (`frame_limit_reset`).
Frame limiter (4a1c:0192): wait until ≥ 5 ticks since the last reset (≈51 fps max).

In-mission palettes: at mission start and in 365e:D285 the palette number is
`tod_palette_index()` (0 pal2 day, 1 paln night, 2 pals dawn/dusk, §5).

## 4. Game clock (1000:2FEA..314B)

| function | behaviour |
|---|---|
| `clk_reset_start_timer` | `g_time = 0`; if the timer is not installed (`DS:25EE == 0`): reset `g_ticks` (4a1c:000E) and register the 256 Hz callback (4592:0BCB: AIL timer, rate 256 Hz); success → DS:25EE = 1 |
| `clk_stop_timer` | if installed: unregister, DS:25EE = 0 |
| `clk_update` | `g_time = g_ticks`; `g_frame_ticks` (DS:ECAA) = `g_time − g_prev_time`, minimum 1; `g_prev_time = g_time` |
| `clk_update_compressed` | `g_time += 0x80`; `g_frame_ticks` as above |
| `clk_resync_raw` | `g_ticks = g_time` |
| `clk_save` | `g_saved_time` (DS:EC9E) = `g_time` |
| `clk_restore` | if `g_saved_time != −1`: `g_time = g_ticks = g_saved_time`; `g_saved_time = −1` |
| `clk_reset` | `g_time = g_ticks = 0`, `g_frame_ticks = 1`, `g_saved_time = −1` |
| `clk_wait(n)` | loop `clk_update()` until `g_time − start ≥ n` |

The timer callback (4a1c:0028) also drives screen shake/palette fades every 8 ticks and joystick
button polling every 4 ticks (see seg_libs.md).

Periodic tests in the code all follow the same pattern: "if `g_time − last ≥ period` then
`last = g_time` and run" (the elapsed value `g_time − last` is stored in `g_elapsed`, DS:ECB4, and
passed to the update).

## 5. Time of day, sky palette and gradients

State: `g_tod_hour` (DS:EC58, 0..23), `g_tod_minute` (DS:EC57), `g_tod_second` (DS:EC59),
`g_t_minute` (DS:EC4E).

* `tod_set(hour, minute)`: sets hour and minute, `second = (g_time >> 8) mod 60` (signed long
  shift/rem), `g_t_minute = g_time`. Mission start uses the mission record: hour = byte
  `g_mission+0`, minute = byte `g_mission+2`.
* `tod_add(h, m)` (8-bit arithmetic): `min += m`; if `min ≥ 60` {hour++, min −= 60}; if `min < 0`
  {hour−−, min += 60}; `hour += h`; if `hour ≥ 24` hour −= 24; if `hour < 0` hour += 24.
* `tod_update()` (every frame except when the map freezes the world): when
  `g_time − g_t_minute ≥ 0x3C00` (60 s): `g_t_minute = g_time`, `minute++`; if `minute % 60 == 0`
  {`hour++`, `minute = 0`; if `hour % 24 == 0` `hour = 0`}. Always recompute `second` as above.
  (Only one minute is added per call regardless of the elapsed time; game time of day advances
  at real-time speed, or 0.5 s per frame in time compression.)
* `tod_palette_index()` and gradient offsets (DS:0530 sky, DS:0532 ground):

| hour | return (palette) | 0530 / 0532 |
|---|---|---|
| 0..4 | 1 (paln) | 0 / 0 |
| 5..8 | 2 (pals) | (hour−4)·32 + minute/2 (both) |
| 9..17 | 0 (pal2) | 0x80 / 0x80 |
| 18..20 | 2 (pals) | 0x80 / 0x80 |
| 21..23 | 1 (paln) | 0 / 0 |

(minute/2 is an arithmetic shift of the signed byte.)

* `tod_draw_sky_ground()` (1000:1AFC), called for every 3D frame with the clip set to the view
  rect `v`: `DS:07A5 = DS:07A4 = 0xFF`; `horizon = v.y + v.h/2`; `frame_limit_wait()`;
  for `i = 0..99`:
  * `d = (detail ≥ 3) ? i : 0`.
  * sky row `y = horizon − i − 1` (if ≥ 0): `k = sky_ofs − d`, but not below `sky_ofs >> 2`;
    `c = gradsky[k]` clamped to 0x80..0x9F. If detail < 2: when `i == 0` record `DS:07A5 = c`
    (no drawing); else draw the full-width horizontal line y (x 0..319) in colour c.
  * ground row `y = horizon + i` (if < 200): `k = ground_ofs + d` (max 0xFF), `c = gradgrn[k]`
    clamped to 0x20..0x5F. If detail < 2: `DS:07A4 = c` and stop the loop; else draw the row.

  Then, every 0xF00 ticks (`DS:EC4A`): if `4 < hour < 8` and `sky_ofs < 0xFF`: `sky_ofs++` and
  `ground_ofs++` (each wraps to 0 above 0xFF) — the dawn sky brightens gradually.
  With detail < 2 the flat colours DS:07A5/07A4 are used by the renderer/fader instead.
* Map background (`view_clear_map_ground`): fill the view rect with `gradgrn[0xB6]`.

### 6.3 Exit
`page_copy_full(); shake_stop(); g_cursor_mode = 1; mis_free_sprites(); 4a37:01BC()`; return
`g_quit_game`. `g_mis_done` is set by the extraction test above or by "End mission" (Esc →

### 6.4 Time compression (Alt-T, handled in 19ac:0CC3)
* On: `4592:04FF(); stop music; play track 5; tc_on()` → `g_tc_state = 3`, clear the message
  queue, queue **"Time Compression On"** (HUD message, 0x7800 ticks).
* Off (Alt-T again, or automatically inside every `msg_show`/`msg_hand_signal` call, i.e. any
  HUD message cancels compression): `tc_off()` → `g_tc_state = 0`, clear queue, `g_ticks = g_time` (real time
  continues from the compressed time), `g_full_redraw = 2`; the hotkey path also stops the music
  and shows "Time Compression Off" (DS:04C4, 0x100 ticks).
* While compressed only the clock box is redrawn (§9.5) and `g_time` advances 0x80 (0.5 s) per
  frame; all world updates keep running on the compressed clock (the manual calls it "app. 4x").

### 6.5 Insertion and extraction
* `mis_start_insertion` (at mission start): `view_set_mode(7)`; `g_orbit_dist` (DS:D8B4) = 0x264;
  clear queue; `msg_show("Insertion", 0x800)`; `g_insertion_clear_time = g_time + 0xA00`;
  Point Man MOVER field +0x3A = 4.
* During mode 7 the camera orbits the Point Man (§7.3), the screen shows the " Insertion  "
  banner and "Esc to skip  -  R to Reinsert". Enter/Esc (hotkeys) or reaching
  `g_insertion_clear_time` call `mis_insertion_clear`: `view_set_first_person()`, then
  `view_set_chase()` (the game continues in the chase view, mode 2), `veg_update(0)`,
  `g_orbit_dist = 0xC0`, `msg_show("Insertion craft clear.", 0x200)`. 'R' selects view mode 0xC
  (reinsertion map) in 19ac:5C8E.
* `mis_start_extraction` (called by the pickup logic 2dbd:350C when the team has boarded): does
  nothing if `g_extraction_end` is already set or the world is a camp world (`g_world_index > 27`).
  Otherwise `view_set_mode(8)`, `g_orbit_dist = 0x120`, clear queue,
  `msg_show("Extraction", 0x1D00)`, `g_extraction_end = g_time + 0x1D00` (29 s), 19ac:00B6
  (mission time/score), stop music and start the end music track:
  if `g_music_state == 2`: track 6; else if the Point Man is dead (STATUS+0xF bit 0x40): 9;
  else if 365e:3FAE(g_campaign, 53BA:3044): 7; else if `g_time < g_contact_until`: 10;
  else if 365e:1BB7(0) > 1: 8; else 6. Finally `g_extracting = 1` (blocks F1/F2/F9/F10).

### 6.6 Music mood and alerts
* `mus_get_mood()`: 0 if `g_music_state == 2`; 2 if `g_time < g_contact_until` (DS:0898);
  1 if `g_time < g_alert_until` (DS:D808); else 0.
* `mus_update_mood()` (every 1.25 s, not in time compression): only when the fade level
  DS:4687 is 0 and the current track `g_music_track` (DS:EFD8) < 6. If the current track is 3 or 4
  (sting tracks) change only when 4592:1B5F reports it finished; otherwise change only if the mood
  differs and is 0..2. Change = stop (4592:1B31) + play mood track (4592:1AD9).
* `mis_check_alerts()` (every 1.25 s): if `g_time ≥ g_alert_until` and 365e:1DFB() (an enemy is
  seen): if `g_time ≥ g_contact_until`: `msg_show("Enemy sighted.", 0x100)` and, if also
  `g_time ≥ g_alert_until + 0x2800` (40 s), the Point Man gives hand signal 2 "Enemy"; then
  `g_alert_until = g_time + 0x1400` (20 s). Independently, if `g_radio_damaged` and
  `g_time > g_radio_repair_time`: `msg_show("Radio repaired.", 0x200)`, `g_radio_damaged = 0`.

| +0x04 | int32 | altitude |
| +0x08 | int32 | z |
| +0x0C | int16 | yaw (1/8 deg) |

* small `g_cam_small` DS:D88A: (−1000, 0, 24, 0), rect (0, 24, 320, 139).

### 7.2 View modes (`g_view_mode`, DS:D844) and keys (19ac:0CC3)

### 7.3 Camera placement — `view_update_camera(mode)` (1000:2544)
`g_view_team` (DS:053E) = 0 unless set below; at the end the 3D sound listener is moved to the
leader of `g_teams[g_view_team]` (4592:000D). `S(a)`, `C(a)` are the engine's sine/cosine of a
1/8-degree angle (2255:61E7 / 61F6); products are `(d · S(a)) >> 8` with 32-bit arithmetic.
* **0**: camera x, z = Point Man position; yaw = Point Man heading (altitude = eye height set by
  `view_set_eye_height`).
* **1**: team `ec86` (map selection): x,z = its leader position; if `ec86 ≥ g_first_enemy_team`
  the low bytes (bits 0..7 of the low words) of x and z are cleared.
* **0xC**: x = DS:0EA0, z = DS:0EA8 (reinsertion point).
* **2, 0xE**: team = Point Man's team (mode 2) or `g_teams[ec8f + g_enemy_view_idx]` (mode 0xE,
  also sets that team's +0x32 = −1); `view_init_orbit_angle(team)`; `d = team+0x30`,
  `a = team+0x32`; camera x = leader.x − d·S(a)>>8, z = leader.z + d·C(a)>>8; yaw =
  `geo_bearing(camera, leader) << 3`; altitude = 0x1800, plus the altitude of
  `g_teams[g_extract_craft_team]`'s leader if 365e:1CDA() (team aboard the craft).
* **3, 4, 0xD, 0xF, 0x10, 0x11, 0x12**: pick the team — 3/4 → `ec8c+0/+1`; 0xF/0x10 →
  `ec8c+2/+3`; 0x11 → `ec87−2` if `g_extra_teams == 2` else `ec87−1`; 0x12 → `ec87−1`;
  0xD → if the target record kind (5149:0012) is 0 the target unit's team (unit +0x1E) is stored
  in `g_target_cam_team` (DS:0538), otherwise DS:0538 is kept (default: first enemy team);
  `g_view_team` = index of that team (19ac:62D1, fallback `ec8f`).
  `view_init_orbit_angle(team)`; `d = team+0x30 << 2` for 3/4/0xF/0x10, unshifted for
  0xD/0x11/0x12; same orbit formula (camera = leader − d·S(a), + d·C(a); yaw = bearing<<3);
  altitude = the leader's altitude (int32 at object +0xA) if it is above 0x1800, else 0x1800.
* **5, 6**: team `ec8c` (5) / `ec8d` (6); while `g_full_redraw == 2` (first frame after a mode
  change) `g_orbit_angle` (DS:D842) = norm(raw bearing from the team leader to the Point Man +
  (15 − rand(30))·8) — a random ±15° offset; camera = leader − `g_orbit_dist_craft`·S/C of that
  angle (DS:D846 = 0xC0); yaw = raw bearing(camera, leader); altitude as in the previous item.
* **7 (insertion)**: target = Point Man. `g_orbit_heading` (DS:D8B8) = raw bearing from the
  objective (DS:0E94) to the Point Man; `g_orbit_dist −= (0x33 · g_frame_ticks) >> 8`.
* **8 (extraction)**: target = leader of team `ec92`; if 365e:1CDA() (craft moving)
  `g_orbit_dist += (0x1D · g_frame_ticks) >> 8`. If not a camp world: heading = raw bearing
  craft → Point Man while `g_orbit_dist < 0x1E0`, else reinsertion point (DS:0EA0/0EA8) → craft
  (camp worlds keep the previous heading).
* 7/8 common: camera x = target.x − dist·S(h)>>8, z = target.z + dist·C(h)>>8,
  yaw = raw bearing(camera, target); altitude = target altitude if it is above 0x1800 and mode
  is 8, else 0x1800.

`view_set_eye_height` (1000:2462): `h = MOVER+0x18` of the Point Man; if negative
`h = 3 − (h >> 3)`; if MOVER+0x26 bit 0x40 add `(something) + 0x24` (eye-level offset, see
seg_2dbd); clamp ≥ 0; main camera altitude = `h << 8`.

## 9. HUD (first-person and chase views)

Text is drawn with 4dcf:000E(y, x, string) in colour word DS:5074 (0xFF0F = colour 15,
transparent) with DS:F424 = 0. `v` = current camera rect, `yb = v.y + v.h`.

### 9.1 Compass tape (`hud_draw_compass`, only if `g_compass_enabled`)
`H` = Point Man heading in degrees; `c = 360 − H` (0 if H = 0). Base line at `y0 = v.y + 16`
from x 0x45 to 0xF9 (colour 0x0F). The tape covers 90 columns × 2 px: column k (x = 0x45 + 2k,
k = 0..90) shows angle `a` starting at `c − 45` (wrapped to 0..359) and increasing by 1 per
column. For each column: if `a % 15 == 0` a tick from `v.y + 14` to `y0`; else if `a % 5 == 0` a
tick from `y0 − 1` to `y0`; if `a == c` a marker from `v.y + 17` to `y0`; if `a % 30 == 0` the label
`g_compass_labels[a/30]` (" N ", " 30", " 60", " E ", "120", "150", " S ", "210", "240", " W ",
"300", "330") at (x = 0x41 + 2k, y = v.y + 6).

### 9.2 Objective marker (`hud_draw_objective_marker`)
If `geo_distance(Point Man, objective DS:0E94) < 15` nothing. Else `o = 360 − bearing(Point
Man → objective)` (0 if the bearing is 0). Walking the same 91 columns, when the column angle
equals `o` draw a caret under the tape at the column x (= 0x45 + 2k): lines
(x, v.y+0x12)→(x−3, v.y+0x15) and (x+3, v.y+0x15)→(x, v.y+0x12). If the objective is not on the
tape: if `c + 180 > 359` and `o < c − 180` then `o += 360`; if `c < o < c + 180` draw ">" at the
right edge — lines (0xFA, v.y+0x14)→(0xF7, v.y+0x11) and (0xF7, v.y+0x17)→(0xFA, v.y+0x14) —
else "<" at the left edge — (0x45, v.y+0x14)→(0x48, v.y+0x11) and (0x48, v.y+0x17)→
(0x45, v.y+0x14). All lines colour 0x0F. (Line helper 2255:1962 takes colour, y1, x1, y2, x2.)

### 9.3 Target info (`hud_draw_target_info`, mode 0 only)
Skipped during full redraws or when the reticle (DS:0534, DS:0536) lies outside the view rect.
The target record is far 5149:0000 (filled by `tgt_acquire` 1000:6225): +0x0E far target,
+0x12 kind (0 unit, 1 world object), +0x18 range, +0x1C cover. `band = wpn_range_band(weapon,
range)` (number of the weapon's three range thresholds ≤ range) and colour `DS:0540[band]`
= {0xE0, 0x0E, 0x0F, 0x14}.
* `hud_draw_target_diamond(x, y, range, -, colour)`: if colour is band-0 colour 0xE0 or the Point
  Man's MOVER+0x24 ≠ 2 (not running), and y > v.y: diamond of 4 lines between (x±8, y) and
  (x, y±8). Then if `v.y < y+10 < yb − 8` and `v.x < x−8 < v.x + v.w − 0x14`: text
  `itoa((range / 3) >> 2, width 3, space padded) + " m"` at (y+10, x−8).
* kind 1 (object): name = the string whose pointer is at +0x22 of the object's 3D model (first
  word of its instance), drawn at (y+0x10, x − 2·(len & ~1)) if `v.y < y+0x10 < yb−8` and
  `v.x < x' < v.x+v.w−0x20`; if 365e:288A(object) (an objective) " Objective" at
  (y+0x16, x−0x14) if `v.y < y+0x16 < yb−8` and `v.x < x−0x14 < v.x+v.w−0x28`.
* kind 0 (unit): label = `g_team_type_names[team+0x26]` (SEAL Team, Boat Support Unit, Seawolf
  Helicopter, Bronco Aircraft, Viet Cong, NV Army, Civilian, Friendly); for SEAL teams (type 0)
  append " b" if `g_extra_teams ≥ 2` and the unit's team is the last team `g_teams[ec87−1]`,
  else " a", and move 4 px left; drawn at (y+0x10, x−0x10[−4]) if inside
  (`< v.x+v.w−0x30`); " Objective" (same rule as above) if 365e:290B(team).

`tgt_acquire(shooter, -, -, record, skip)` (1000:6225, auto-target, called by the input code):
`lock` = the record holds a target (kind ≠ −1) and `skip` is 0 (then only that target is
re-validated). If `g_target_structures`: walk the world objects in table order; with `skip` set,
objects are ignored until the current target has been passed; the first object with cover byte
100 that lies within ±10° of the shooter heading (`geo_in_fov`) and within 0x4B0 units
(and is the current target when `lock`) is examined: `los = wld_los_cover(shooter, object)`;
if `los < 100` and (kind is not 0xA/0xB or distance < 0x79) it becomes the target (kind 1,
range, cover; the old target's instance flag +3 bit 2 is cleared) — the walk stops at that first
candidate either way. Then walk the members of every foot team (type 0 or > 3) except the Point
Man's team: the first member within ±16°, alive, not captured (MOVER+0x26 bit 0x20 clear), with AI
flag +0x6C bit 7, closer than 0x475 and than the structure candidate, with `los < 100` becomes
the target (kind 0, instance+3 |= 4) and the function returns 0. Otherwise it returns 1 if a
structure was examined within range, else clears the record (target NULL, kind −1) and returns −1.

## 10. Message queue (1000:7B06..840B)

Ring buffer `g_msg_queue` DS:3716, 8 entries × 0x52 bytes; `g_msg_head` DS:ED22,
`g_msg_count` DS:ED24, enabled flag DS:39A6.

| off | type | meaning |
|---|---|---|
| +0x00 | int16 | style (−1 = free; 0/1 dialog lines, 2 HUD line, 3 hand-signal icon line, 6 special) |
| +0x02 | int16 | sticky: the last remaining sticky message cannot be removed |
| +0x04 | int16 | duration in ticks (0 = shown together with the previous message) |
| +0x06 | int32 | expiry time (−1 = not started) |
| +0x0A | int16 | kind: 3 = HUD overlay line, 4 = hand-signal picture, 0..2 = dialog with font DS:EEF4[kind] |
| +0x0C | far char* | original text |
| +0x10 | char[64] | copy of the text (texts ≥ 63 chars are replaced by "Dlg Str Overflow") |
| +0x50 | int16 | hand-signal icon number (style 3) |

* `msg_queue_add(text, kind, duration, style, sticky)`: fails (0) if disabled or 8 entries are
  queued. Slot `(head + count) % 8`; `count++`. If `kind != 4 and style == 3`: icon = duration
  argument, and the real duration becomes 0 if that argument was −1, else 0x300.
* `msg_queue_remove(i)`: if `count == 1` and the entry is sticky → refuse (0). Else `count−−`
  (if > 0), style = −1, text[0] = 0; if `i == head`: `head = count ? (head+1) % 8 : 0`.
* `msg_queue_clear`: remove the head until count is 0 or a removal is refused.
* `msg_queue_tick` (every loop iteration): head entry: if its expiry is −1 set it to
  `g_time + duration`; else if `g_time > expiry` remove it and, if the new head has duration 0,
  remove that too.
* `msg_queue_skip`: if count > 1 and the head has started, remove it (and a following zero-duration
  one).
* `msg_draw_queue` (each rendered frame): if the head is valid and `g_time < expiry` draw it
  (`msg_draw`); if count > 1 and the head is not style 3, search forward for a style-3 entry, start
  its timer if needed and draw it while it is on screen (head index restored afterwards).
* `msg_draw` (head, plus the next entry):
  * kind 3: `y` = map modes: 0x99 for style 3 else 0xC1; view mode 0: 0x96; other modes: 0x84.
    Style 3: `msg_draw_signal_icon(x 0x22, y−0x14, icon, expiry, duration)` and the text centred
    on x = 0x22 (x = 0x22 − 2·len) at y−0x3C; the next entry (if style 3) at y−0x11, same
    centring. Other styles: text centred on the screen at y (365e:94DE).
  * kind 0..2: font DS:EEF4[kind]; style 6 → 365e:93BC, else 365e:9438(text); also the next
    entry unless it is kind 4.
  * kind 4: `msg_draw_signal_picture(style % 8)`: frame `style%8` of sprite bank 0x2140 drawn
    centred (x = 160 − w/2, y = 116 − h/2 region) inside a box (365e:2EBA), `g_full_redraw = 2`.
* `msg_draw_signal_icon`: frames table DS:36E8; progress = `(g_time − start)·10 / duration`
  (start = expiry − duration), clamped to ≥ 0 and to `frames[icon+1] − frames[icon]`; if non-zero
  add `frames[icon] − 1`. Draw background frame (4,5) of the `hnds` bank (0x1E70) with its
  bottom-centre at (x, y), then frame (f/8, f%8) as a 30×30 image at (x−15, y−31).

Convenience wrappers:
* `msg_show(text, dur)` = `tc_off(); msg_queue_add(text, 3, dur, 2, 0)`.
* `msg_hand_signal(unit, n)`: `tc_off()`; if hand-signal graphics are off (DS:348B = 0):
  `msg_queue_add(signal_name[n], 3, 0x100, 2, 0)`; else
  `msg_queue_add(unit == Point Man ? " " : unit personnel name, 3, n, 3, 0)` followed by
  `msg_queue_add(signal_name[n], 3, −1, 3, 0)`. Signal names (DS:1CB0): Halt, Danger, Enemy,
  Trap, Under Fire, Objective, Search, Secure, Column, In-Line, VeeWedge, Diamond, Cease, At Will,
  Field, Target.
* `msg_say(name, text)` (speech): prefix = `name + ': "'` (or `'"'` if the name is empty). If
  `prefix + text` < 0xA0 chars: if < 0x37 (55) one line `prefix + text + '"'` (kind 1, 0x700
  ticks, style 0) plus a " " line (kind 1, duration 0); else split: start at
  `s = min(len(text)/2 − 8, 0x36 − len(prefix))` and advance while `text[s]` is neither ' ' nor
  NUL and `s < len`; line 1 = prefix + text[0..s) (0x700 ticks), line 2 = text[s+1..] + '"'
  (duration 0). Returns the text length (nothing is queued when the text is empty or
  prefix+text ≥ 0xA0).
* `radio_call(text, team)`: if team < `g_first_enemy_team` or its leader is > 600 units from the
  Point Man (radio needed): when the radio is damaged show "Radio damaged." (0x200) and return 0;
  for teams of type 1 or 2 (boat, helicopter): while `g_time ≤` their busy time (leader
  MOVER+0x44) return 0; otherwise with `rand(100) < 5` set the busy time to `g_time + 0x1E00`
  and return 0; then play radio sound 0x1D twice (parameters 0x200 and 0x500) and prefix the
  text with "Radio: ". Without radio the text is shown unprefixed. Finally `msg_queue_clear()`,
  `msg_show(text, 0x200)`, return 1.

## 12. World objects

### 12.1 Loading (`mis_load_world(n)` = 2255:01E7, `wld_load(n)`, `fx_create_pools`, 365e:129A
(teams), 2255:02B0, `mis_scan_specials`)
`wld_load(n)`: `g_world_index = n`; name = `g_world_names[n]` + ".w" (0..5 mekong1-6, 6..11
rungsat1-6, 12..17 mekong7-12, 18..22 rungsat7-9, rungst10, rungst11, 23..26 bassac1-4,
27 north1, 28..32 camp1-5). The file consists of **18-byte records**:

| off | type | meaning |
|---|---|---|
| 0 | u8 | heading code h: degrees = 2h, plus 1 if (2h mod 15) ≠ 0; stored as degrees·8 |
| 1 | u8 | unused |
| 2 | int32 | x (world units) |
| 6 | int32 | z |
| 10 | u8 | object type (index into far table 514B, 6-byte entries {shape, kind, flags}) |
| 11 | u8 | unused |
| 12 | u16 | flags → object +8 (bit 0 = objective/special) |
| 14 | u16 | hit points → object +0xA |
| 16 | u8 | cover value → object +0xC |
| 17 | u8 | height/solidity → object +0xD |

For each record (up to `size/18`, max 524 objects) a 14-byte object is allocated:
`+0 shape`, `+2 far 3D instance` (2255:0234(shape, x, z, type flags)), `+6 kind`, `+8 flags`,
`+0xA hit points`, `+0xC cover`, `+0xD height`. Overrides: kinds 4, 5, 7, 8, 9, 0xB, 0x12 →
cover 0, height 0x1F; kind 0x10 → hp 0x32; kind 3 → hp 0x19; kind 6 → height 0x7F; types 0x28 and
0x2B → cover 99; type 0x20 → cover 100. Then `<world>.wd` is loaded into DS:ECB8, and 126 spare
objects (type table entry 0x26) are created in DS:31BA and appended to the table (kind 3 → cover
0x19, height 0x3F, hp 0x19; else cover 100, height 0x7F, kind 6 → hp 0x32).
Kinds seen in this code: 0 destructible structure (counted by `wld_count_destroyed`,
secondary fire/smoke on destruction), 3/6 trees?, 5 invisible blockers, 7/8/9 water, 0xA/0xB
huts/bunkers, 0x10/0x11/0x12 others.

### 12.2 Queries
* `geo_distance(a, b)` = `(max(|dx|,|dz|) + 3·min(|dx|,|dz|)/8) >> 8` (the 3/8 term uses a signed
  32-bit shift of `3·min`), clamped to 0x7FFF.
* `geo_bearing(a, b)` = atan2 (2255:63D7) >> 3 degrees; `geo_pitch` via 2255:64FD.
* `geo_in_fov(a, half, h, b)`: `half = min(|half|, 180)`; `d = bearing(a,b) − h + 180`, reduced
  to 0..359; true if `180 − half ≤ d ≤ 180 + half`.
* `wld_los_cover(unit, target_pos)` (`g_los_calls++`):
  ```
  total = 0; from = unit's 3D object; last = 0
  while total < 100:
      hit = trace(from -> target_pos)            ; 1000:314C
      if hit == 0 or hit == last: break
      last = hit; from = hit
      obj = wld_object_from_hit(hit); if obj == NULL: continue
      if geo_distance(unit, target_pos) <= 5: break
      if obj x and z (32-bit) equal target_pos x and z: break
      total += obj.cover
  return total                                    ; < 100 = visible
  ```
* `wld_probe_kind(pos, kind)`: move the probe object DS:2FA8 to `pos` (altitude 0), trace 1000:318E
  and return 1 if the hit object's kind matches (−1 any; kind 5 temporarily makes kind-5 blockers
  visible). `wld_ground_type(pos)` = 2 if kind 7, 8 or 9 is hit (water) else 1.
* `wld_nearest_object(pos, kind)` (kind 7 also accepts 9, −1 any; initial best distance 24000).

    grenade/throw modes, flags & 0x18 == 0) or type 0x21/0x1A; 2dbd:41A4 initialises its flight

## 14. AI noise events (far 53BA:26DA, 20 × 0x18 bytes)
Fields: +0 type, +2 level (far table 525C:type·2), +4 heard flag, +6 far source team,
+0xA position (12 bytes), +0x16 free flag. Types: 5 boat, 6 aircraft, 7 helicopter, 8 walking,
9 running, 10 wading, 0xD cough, 0xF sneeze, 0x11 explosion, 0x12 enemy radio, 0x13 weapon.
* `noise_update` (every 4 s): for each team `noise_from_team`; then for every used event: if not
  yet heard set heard = 1, else free it.
* `noise_from_team`: foot teams (type 0 or > 3): on land running (MOVER+0x24 == 2) → type 9,
  level 15 (footstep sound 0x19 unless it is the Point Man's team), walking → type 8, level 10;
  in water and moving → type 10, level 5, sound 0x18. Level −= 5·(STATUS+0xA/30 − STATUS+8/30 +
  STATUS+0xC/30). Craft: type 5/7/6 for team type 1/2/3, level 100. Enemy teams (4/5) carrying a
  radio (item 0) with AI flag +0x6C bit 2: type 0x12, level 99. Create the event if
  `rand(100) ≤ level`; if moving and `rand(100) ≤ 5`: cough (type 0xD, sound 0x21) if
  `rand(100) ≤ 0x4B` else sneeze (type 0xF, sound 0x22).
* `noise_from_weapon` (type 0x13, level = weapon table +0x16 ·4, or 6 without a weapon) and
  `noise_from_explosion` (type 0x11, level 525C:0022).
* `noise_hear(listener, out_pos)`: for events not from the listener's team where the sides are
  opposed (enemy teams 4/5 vs types < 4 or 7), or any weapon event: `lvl = level − distance`
  (min 0); difficulty *Intelligence* 0 makes enemies ignore `lvl < 91`, 1 ignores `lvl < 31`; a
  listener whose record +0x83 is '0' ignores teams accepted by 365e:1544 (lvl = −1). The loudest
  event's source position is copied to `out_pos`; returns 1 if the best `lvl > 0`.

## 15. Procedural scenery (`veg_update(force)`, 1000:784D)
Visual only. "Kept" = bit 0x20 of instance byte +3; "visible" = bit 0 of +2 (both set with
`|= 0x2001`). Altitudes compared below are 24.8 values: `0x12BFF` ≈ 300 units.
1. Ground cover — only if detail ≥ 2. Unless `g_veg_force`: skip if 365e:1CDA() (aboard a craft)
   or the Point Man's altitude > 0x12BFF, or if he is within 0x8000 (128 units) of the last
   placement position (DS:ED18/ED1C) in both x and z. Otherwise remember his x/z and call
   `veg_place_ground_cover(pos)`:
   * n = 0x62 cells if detail ≥ 5 else 0x31; clear the kept bit of all spare objects (DS:31BA).
   * base = position with the low 16 bits of x and z cleared (256-unit grid).
   * for each cell offset (ox, oz) of DS:3560 (units): `cell = base + (ox<<8, oz<<8)`. Unless
     forced, look for an existing not-kept spare whose x and z equal the cell in bits 15..30
     (128-unit granularity); if found mark it visible+kept, altitude 0, next cell.
   * otherwise (or when forced) take a spare whose instance is hidden (`fx_pool_alloc_wrapped`);
     if `wld_probe_kind(cell, 5)` hits a blocker keep it hidden; else visible+kept,
     x = cell.x + (rand(0x80)<<8), z = cell.z + (rand(0x80)<<8), altitude 0,
     type = `veg_random_cover_type()` (0x27..0x2F) → shape/kind from far table 514B,
     flags 0, hp 100, heading = rand(360)·8; kind 3 or 0x11: cover 0x19 (0x4B for 0x11),
     height 0x3F; else cover 0x32 (kind 6) / 99 (shape 0x9350) / 100, height 0x7F.
   * finally every spare not kept is hidden and its position zeroed; `g_veg_force = 0`.
2. Camera-relative vegetation — only when not on the map (mode ≠ 1). Unless `force`: return if
   the camera altitude > 0x12BFF, 365e:1CDA(), or the camera moved < 0x2001 (32 units) in both x
   and z since the last placement (DS:CEB2/CEB6) and its yaw changed by < 16 (2dbd:0006). If
   detail > 2: remember x, z, yaw and call `veg_place_camera_scatter(cam, yaw)`:
   base = camera x/z with the low words masked to 0xC000 (64-unit grid); for each of the 49
   offsets (u, v) at DS:348C: first `yaw = norm(yaw + 0x168)` (45° further for every entry;
   `norm` = 2255:6205, wrap into 0..0xB3F), then rotate (u, v − 0x40) (2255:62D0 with the table
   at DS:54F6) by `(yaw & ~7) − ((yaw >> 3) mod 90)·8` (the yaw snapped down to a multiple of
   90°), keep bits 0xFFC0 of the rotated components and add them `<<8` to the base. Match an existing not-kept
   sprite of pool DS:2FBC by (x low word & 0xE000, x high word) and the same for z; else
   allocate a hidden one: visible+kept, x/z = cell + (rand(15)<<8), altitude 0, heading
   rand(0x167)·8, shape `veg_random_tree_shape()`, hidden again if a kind-5 blocker is there.
   Afterwards sprites that were not kept are hidden, kept ones are unmarked.
3. If `force`: `veg_place_distant_trees(cam, yaw)` (detail > 1): base as in 2, altitude 0xC00;
   for the 4 offsets at DS:3550 (not reduced by 0x40) the same stepping/snapping rotation; each
   uses a hidden object from pool DS:3100 placed at cell + (rand(0x80)<<8) in x and z and
   configured by `veg_setup_distant_tree`.
`veg_reset` hides all of these (vegetation parked at (0x3A9800, 0x3A9800)), clears the tracking
positions and sets `g_veg_force = 1`.
